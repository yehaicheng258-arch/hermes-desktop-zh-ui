## 首个公开版本

把 Hermes 桌面端里那些英文的技能卡片、插件目录、工具集页、连接器目录**就地换成简体中文**的运行时插件。

## 包含什么

- **词库 6,055 条**：官方 optional-skills、公共 skills feed（每分类前 16 条）、插件目录、工具集页、Connectors 页（门户公开目录 + 本地 MCP manifest）、上游 `i18n/en*.ts` 英文字面量
- **整段精确匹配**：只有整段文本与词库键完全相同才替换，并跳过 `pre / code / kbd / input / textarea / select`、`contenteditable`、`[data-zh-skip]` —— 聊天正文、代码块、命令永远不会被误翻
- **状态栏「中 N」开关** + `⌘K` 命令，开关状态持久化
- **运行时零网络、零后端**；翻译只在构建期做一次，带缓存
- 四种安装方式：`install.ps1` / `install.sh` / 手动放 `plugin.js` / 自己构建

## 安装

```powershell
irm https://raw.githubusercontent.com/yehaicheng258-arch/hermes-desktop-zh-ui/v1.0.0/install.ps1 | iex
```

## 已知限制

- 公共 skills feed 有 10 万+ 条，只收录每分类前 16 条；搜索深处的长尾仍是英文（可用 `--per-cat` 自行扩大）
- 词库是构建时快照，新上架的技能要重跑构建才变中文
- 只影响显示，不改任何文件、不影响 Agent 读到的原文

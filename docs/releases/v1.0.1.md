## 修复

- **`install.ps1` 改为纯 ASCII 文案**：Windows PowerShell 5.1 按 ANSI 解析无 BOM 的 `.ps1`，原先带中文的提示行在一行安装后会输出乱码（装出来的文件是好的，只是最后那行提示变乱码）。安装行为不变，仍然是把 `dist/plugin.js` 装到 `<HERMES_HOME>/desktop-plugins/zh-ui/`。

## 安装 / 升级

```powershell
irm https://raw.githubusercontent.com/yehaicheng258-arch/hermes-desktop-zh-ui/v1.0.1/install.ps1 | iex
```

macOS / Linux：

```bash
curl -fsSL https://raw.githubusercontent.com/yehaicheng258-arch/hermes-desktop-zh-ui/v1.0.1/install.sh | bash
```

想固定版本，也可以直接下载本页 Assets 里的 `plugin.js`，丢进 `<HERMES_HOME>/desktop-plugins/zh-ui/`。
仓库里的 `main` 分支会继续更新，**要稳定就用这个 tag 的地址**。
